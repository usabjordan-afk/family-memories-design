# Family Memories Design

Premium marketing site for on-site tournament apparel printing — React + Vite + React Three Fiber.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Interactive 3D apparel uses meshopt-compressed glTF garments in `public/models/`.
- Brand logo lives in `public/img/`.
