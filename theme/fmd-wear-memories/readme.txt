=== Family Memories Design — Wear Memories (v2.0.0) ===

УСТАНОВКА (только через wp-admin, FTP не нужен)
1. wp-admin → Внешний вид → Темы → Добавить → Загрузить тему → выбрать fmd-wear-memories.zip → Установить → Активировать.
   (Если тема уже стоит: WordPress предложит «Заменить текущую загруженной» — нажмите.)
2. Логотип: Внешний вид → Настроить → Свойства сайта → Логотип → загрузить оригинальный logo2x.png.
3. Внешний вид → Настроить → Wear Memories:
   • First screen — тексты первого экрана и кнопок
   • Prices — цены «starting at» (сейчас стоят плейсхолдеры $25 / $40 / $45 / +$8)
   • Booth photo — фото тента 10×10
   • 3D studio models — загрузить hoodie / crewneck / t-shirt .glb
     (glTF binary без Draco-сжатия; если модель стоит боком — выбрать поворот 90/180/270)
   • Contact & booking email — куда приходят заявки (по умолчанию info@familymemoriesdesign.com)
4. Настройки → Чтение → «Ваша домашняя страница отображает»: любая. Тема сама рисует главную (front-page.php).

ЗАЯВКИ
• Форма отправляет письмо на email из Customizer, клиенту уходит автоответ.
• Копия каждой заявки сохраняется в wp-admin → Bookings, даже если почта не дошла.
• Если письма не приходят — хостинг не умеет отправлять почту: поставьте плагин WP Mail SMTP.

ДИЗАЙНЫ
• wp-admin → Designs → Add design: название + изображение записи (PNG с прозрачным фоном).
  Порядок (Attributes → Order) задаёт номер Design 01, 02…
• Пока своих дизайнов нет, показываются 8 встроенных.

3D-СТУДИЯ
• Свой лёгкий WebGL-движок (~30 КБ вместо ~600 КБ у three.js), грузится только когда пользователь доскроллил до студии.
• Один canvas на страницу, рендер засыпает, когда ничего не двигается.
• Без загруженных .glb используются встроенные угловатые модели.
